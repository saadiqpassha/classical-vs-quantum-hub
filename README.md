Every quantum advantage or "quantum supremacy" claim rests on the assumption that a classical computer can't reproduce the result efficiently. That assumption gets tested — repeatedly — by real open-source classical simulation software: GPU-accelerated state-vector simulators, tensor-network methods that compress the classical description of a quantum state, and contraction-optimization techniques built specifically to challenge supremacy claims. This directory maps that software.

The main Quantum Computing Hub already covers general-purpose classical simulators (Qiskit Aer, Qulacs, QuTiP, Intel Quantum Simulator). This directory goes further — into GPU/HPC-scale simulation, tensor-network libraries, and the specific contraction techniques used in classical challenges to quantum advantage claims.
