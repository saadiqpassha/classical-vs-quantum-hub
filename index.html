The Classical vs Quantum simulation tool directory

Every "quantum advantage" claim rests on an assumption: that a classical computer couldn't do it faster. This is the open-source software actually used to test that assumption.

A note on scope: the main hub already covers general-purpose classical simulators (Qiskit Aer, Qulacs, QuTiP, Intel Quantum Simulator). This directory goes further — into GPU/HPC-scale classical simulation, tensor-network methods, and the contraction-optimization techniques specifically used to classically challenge quantum supremacy claims.
